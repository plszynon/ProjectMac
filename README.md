# projectMac

A local browser replica inspired by macOS Sierra 10.12. It recreates the desktop shell and selected built-in apps with HTML, CSS, JavaScript, and an original vector Sierra-style wallpaper. It is a simulation; it does not boot or contain macOS.

## Open it

Double-click `index.html`. The first launch shows a short Setup Assistant; later launches show the local demo login screen. Setup choices, notes, reminders, wallpaper, Dock size, and demo app installs are stored in this browser.

## Desktop features

- Sierra-inspired boot, Setup Assistant, login, wallpaper, translucent menu bar, Apple menu, status menus, Notification Center, Spotlight, and Dock
- Finder-style locations and search, movable/resizable windows, minimize, zoom, window stacking, and restart
- Sierra-era System Preferences grid with working General, Desktop & Screen Saver, Dock, Network, and Energy Saver demo panes
- Local demo versions of Safari, Mail, Contacts, Calendar, Notes, Reminders, Maps, Photos, Messages, FaceTime, iTunes, iBooks, Siri, and App Store
- Demo App Store installs for Calculator, Color Studio, and Reader; these appear in Launchpad

The App Store's Get buttons install only browser demo apps. The external link opens Apple's Mac App Store catalog; downloading and installing Mac software requires a compatible Mac and its App Store app. If `InstallOS.dmg` is placed next to this project, the webpage will not read, mount, or execute it. A website cannot boot the installer or turn a Windows computer into a Mac.
