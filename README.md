# projectMac

A self-contained browser replica inspired by macOS Sierra 10.12. It is a website, not a bootable Mac or a copy of the macOS operating system.

## Open it

Double-click index.html in this folder. The first launch shows a startup screen and a setup assistant. After setup, it shows a login screen on later launches.

No package install or server is required. The source is split across index.html, styles.css, and app.js.

## What works in the replica

- Sierra-style mountain desktop, menu bar, dock, and app windows
- First-run setup screens, local profile name, and simulated restart/login
- Finder-style file window, Launchpad, Safari-style start page, Photos, Calendar, Notes, Messages, System Preferences, and Siri
- Movable, resizable, minimizable, and maximizable app windows
- App Store window with demo installs that add working Calculator, Color Studio, and Reader apps to Launchpad
- A link to Apple's official Mac App Store catalog

Demo installs stay in this browser and do not download Mac applications. Real Mac App Store installs require a compatible Mac and the official store. The Apple installer file in this folder is not loaded or executed by the website.
