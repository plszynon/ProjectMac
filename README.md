# projectMac

A self-contained, browser-based desktop concept inspired by macOS 27 (Golden Gate).

## Open it

1. Open this folder on your Desktop.
2. Double-click index.html.
3. It opens as a local website in your default browser.

No package install or server is required. For local development, edit styles.css for appearance and app.js for desktop behavior, then refresh the browser.

## Included

- Translucent menu bar and dock
- Finder-style file window, Launchpad, Safari-style start page, Photos, Calendar, Notes, Messages, and Settings
- Draggable, resizable, minimizable, and maximizable app windows
- Spotlight-style app search with Ctrl+Space (or Command+Space on Mac)
- Dark appearance and three wallpaper choices
- Notes saved in this browser on this device

The browser start page opens DuckDuckGo searches and selected external sites only after you click. This is a visual web demo; it does not contain or run the macOS operating system.
